## İlkeler

- **Kimlik:** Her istekte `User-Agent: ChemBridge/<sürüm> (+<SITE_URL>; mailto:<CONTACT_EMAIL>)`.
  E-posta adresi kodda yok; `CONTACT_EMAIL` ortam değişkeninden (GitHub Actions → repository variable)
  okunur. Yoksa Crossref'in public havuzu kullanılır ve aralıklar buna göre uzatılır.
- **robots.txt:** RSS/web kaynakları için her çalıştırmada (24 saat önbellekli) kontrol edilir; izin
  yoksa akış atlanır. API uç noktaları kendi kullanım şartlarına tabidir (ör. `export.arxiv.org`
  genel tarayıcılara `Disallow: /` der ama API kullanımı arXiv API ToU ile düzenlenir).
- **Koşullu istek:** ETag / Last-Modified değerleri `state/http-cache.json` içinde saklanır;
  `304 Not Modified` alan akış o gün yeni kayıt üretmez.
- **Lisans:** Yalnızca meta veri ve en fazla 600 karakterlik özet alıntısı yayımlanır. Tam özet,
  yalnızca lisansı yeniden dağıtıma izin veren kayıtlarda (arXiv CC0 meta verisi, CC lisanslı
  preprint'ler) iç durumda saklanır; tam metin hiçbir zaman indirilmez. Her kart orijinal kaynağa
  bağlanır ve kaynak adını gösterir.
- **Bot koruması:** Cloudflare/WAF doğrulaması döndüren kaynaklar atlanır; korumayı aşmaya yönelik
  hiçbir teknik kullanılmaz.
